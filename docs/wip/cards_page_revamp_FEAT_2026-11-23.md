## 1. 問題與動機

- 頁面叫「卡片瀏覽」，其他頁都是短名稱，使用者要改成「卡片」。
- 卡片頁的篩選和知識圖譜是兩套：知識圖譜工具列有卡片類型、筆記類型、層數、麵包屑；卡片頁只有欄位搜尋自己的「欄位搜尋：［卡片類型］」選單，而且一定包含所有子牌組，不能只看這一層。
- 欄位搜尋的排版擠：選單、欄位按鈕、條件、搜尋按鈕、Anki 語法一路往下疊；新增條件時直接跳出來，沒有過渡。

## 2. 目標與非目標

**目標**
- G1 頁面標題與使用者看得到的「卡片瀏覽」改成「卡片」。
- G2 共用元件「牌組條件列」：卡片類型、筆記類型（類型有兩種以上時）、層數、麵包屑。知識圖譜的工具列左半改用它，卡片頁的清單也用它。
- G3 卡片清單可以選「顯示幾層」：1 層＝只有這個牌組本身，2 層＝再加下一層子牌組，3 層，全部（預設，＝現在的行為）。
- G4 卡片類型直接篩清單（只列這種卡片的筆記類型）；欄位搜尋跟著條件列選的卡片類型，拿掉它自己的下拉選單。
- G5 新增條件、打開「進階：Anki 語法」時有展開動畫；系統設定「減少動態效果」時不播。

**非目標**
- 欄位條件的組法（後端 `search_query`）、標籤自動完成：不動。
- 卡片類型、層數放進網址：跟知識圖譜一樣記在瀏覽器（localStorage），網址仍只放牌組、搜尋語句、頁碼、卡片。

## 3. 設計決策

### D1 名稱
- `PageHeader` 標題「卡片瀏覽」→「卡片」；其他使用者看得到的字串（例如建卡失敗提示「請先到卡片瀏覽頁確認」）一起改成「卡片頁」。程式註解裡的「卡片瀏覽」照舊（不影響使用者）。
- 側欄的 `Cards` 不動（側欄都是英文）。

### D2 共用的牌組條件列（`components/shared/DeckScopeBar.tsx`）
- 從知識圖譜工具列左半抽出來，內容依序：卡片類型選單 → 筆記類型選單（目前的卡片類型有兩種以上筆記類型時）→ 呼叫端插入的額外選單（知識圖譜的「名稱欄位」）→ 層數選單 → 麵包屑（點上層回到那個牌組，牌組不存在時標「已不存在」）。
- 選項由呼叫端給：知識圖譜只列開放圖譜的卡片類型、層數只在樹狀圖譜出現；卡片頁列所有卡片類型，最前面多一個「全部卡片類型」（預設），層數一直都有。
- 知識圖譜不是樹狀圖譜時原本顯示「牌組：X」文字，改成同樣的麵包屑（兩種模式一致，也能點上層）。
- 層數選項沿用知識圖譜的 1 / 2 / 3 / 全部（`0`）。

### D3 卡片清單的篩選（API）
- `GET /cards` 新增兩個參數：
  - `note_type`（可重複）：只列這些筆記類型；省略＝不限。前端依條件列換算：選了筆記類型就是那一種，只選卡片類型就是它的全部筆記類型，「全部卡片類型」不帶。
  - `depth`（整數，`0` 或省略＝全部）：只列牌組往下幾層。後端加排除條件：`depth=1` 排除 `deck:"X::*"`，`depth=2` 排除 `deck:"X::*::*"`，以此類推；全部牌組時 `depth=1` 只列最上層牌組（排除 `deck:*::*`）。牌組名照現在的方式跳脫，`::*` 是萬用字元不跳脫。
- 卡片頁的狀態：卡片類型、筆記類型、層數記在 localStorage（卡片類型沿用 `cards_field_search` 的 `handler`，不另開鍵；層數 `cards_depth`），改了回到第 1 頁。清單的查詢鍵加上這三項。

### D4 欄位搜尋跟著卡片類型
- 拿掉 `FieldSearchPanel` 頂端的「欄位搜尋：［卡片類型］」選單；條件列選的卡片類型有開放欄位搜尋（`capabilities.search` 且有 `search_fields`）時，下方出現欄位按鈕與條件；「全部卡片類型」或沒開放的類型只有 Anki 語法。
- 換卡片類型時條件清空（和現在換選單一樣，欄位按鈕不同）。
- 沒有條件時不再需要「列出全部 X」的說明：卡片類型本身已經篩過清單。

### D5 排版
- 清單標題區由上到下：麵包屑＋「＋」建卡按鈕同一列 → 條件列的選單（卡片類型、筆記類型、層數，會換行）→ 欄位按鈕（chip）→ 條件（每列：欄位名、輸入框、移除）→ 搜尋 / 清除條件 →「進階：Anki 語法」→ 張數。
- 麵包屑取代原本的牌組名標題；長牌組名照樣換行，「＋」固定在右上。
- 窄欄（三欄並排）與觸控的尺寸規則照舊（container query、`pointer-coarse`）。

### D6 展開動畫
- 新增的條件：高度與透明度從 0 展開（約 150ms）；移除時直接拿掉（不做收合動畫，避免移除後還佔位、輸入框焦點錯亂）。
- 「進階：Anki 語法」改用現有的 `ui/collapsible`，內容以 `animate-collapsible-down` / `up` 展開收合（`tw-animate-css`）。
- 動畫都包在 `motion-safe:` 裡，系統開了「減少動態效果」就不播。
